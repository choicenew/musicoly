# GitHub Open Source Alignment (GitHub 权威开源对齐与零盲猜协议)

## 0. 核心定位
在涉及第三方 API 接入、逆向接口处理、签名反爬算法、Header 指纹与 Cookie 维持逻辑时加载本技能。

---

## 1. 核心铁律 (Iron Rules)

### 1.1 绝对禁止盲猜与闭门造车
* Agent 严禁凭借过时记忆、凭空猜测或自行推演任何第三方 API 的 Endpoint、签名算法、Header 指纹或 Cookie 逻辑。
* Agent 的个人逻辑在社区验证结果面前不值一提。

### 1.2 强制对齐 GitHub 最新权威开源库
* 面对任何 API 逆向、第三方 Provider 接入或报错处理，Agent 必须**第一时间去 GitHub 上检索并阅读最新、星数高、近期活跃维护的权威开源仓库源码**；
* 必须 1:1 严格复制和对齐开源库中被千万开发者验证过的真实 URL、Header、Cookie 维持和签名逻辑。

### 1.3 数据说话，结果导向
* 评价任何修改的唯一标准是**真实的测试数据**（状态码 200 OK、毫秒级耗时、正确的返回串）；
* 失败就是失败，严禁展示无意义的中间推理过程，直面数据，改对为止。
