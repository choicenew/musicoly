# Isolate Concurrency & Offloading (副线程 Isolate 异步并发与计算下沉规范)

## 0. 适用场景
遇到 CPU 密集型运算、大文本正则清洗、矩阵推算或网络资源预探测时加载本技能。

---

## 1. 核心规约
1. **重型计算必须下沉 Isolate**：
   - 凡是预估耗时超过 16ms 的数据解析、大体积 JSON 反序列化、图像特征提取与文本分词，必须强制使用 Flutter 的 `compute(entryFunction, message)` 派发给 Isolate 执行；
2. **主 UI 线程专注**：
   - 主线程只负责 UI 视图树构建与 120 FPS 渲染交互，严禁在主线程直接执行阻塞式计算；
3. **独立 Worker 状态隔离**：
   - 副线程任务必须保持纯函数特性，输入与输出通过标准不可变对象传递，不共享内存状态。
