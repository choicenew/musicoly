# Autonomous Goal-Driven Orchestrator Protocol (自主目标推进与状态机引擎)

## 0. 核心定位与原则
本规约对标 SWE-agent、Cline 与 Roo Code 的 Orchestrator 核心调度机制。
**核心原则**：当接收到用户的研发大目标、或《产品开发手册》定稿后，**AI 必须自主推演全链路执行计划，严禁中途停顿发呆等待用户逐一引导**。AI 作为自驱动工程总调度，必须主动推进状态机，直至全链路 100% 跑通交付。

---

## 第一章：目标分解与有向无环图 (Goal DAG Decomposition)

接收到任何大任务时，必须先在内存与计划中完成 **有向无环图 (DAG)** 拆解，禁止盲目无序动手：

```text
┌────────────────────────────────────────────────────────┐
│                   顶级业务目标 (Goal)                    │
└──────────────────────────┬─────────────────────────────┘
                           │ 自动 DAG 拓扑分析
                           ▼
  [Node 1: 契约与实体层] ──► [Node 2: 数据驱动与持久化]
                                     │
                                     ▼
  [Node 4: 表现层与交互]  ◄── [Node 3: 核心服务与状态中枢]
           │
           ▼
  [Node 5: 全链路实测与质量门禁] ──► [最终交付 (Goal Achieved)]
```

### DAG 构建铁律：
1. **依赖拓扑前置**：Node 2 必须等待 Node 1 契约锁定后才能编写；Node 4 必须直接消费 Node 3 状态，严禁跨层篡改底层实现。
2. **单节点原子性**：每一个 Node 必须是一个自闭环、可独立进行单元测试的最小功能单元。

---

## 第二章：自主状态机推进流 (Autonomous State Machine Loop)

每个节点严格遵循四阶状态机运转，**前一阶段全绿自动解锁并推进下一阶段**：

```text
[PENDING] ────► [IN_PROGRESS] ────► [SELF_VERIFYING] ────► [COMPLETED]
                     ▲                      │
                     │ (测试未通过自动回滚重构)  │
                     └──────────────────────┘
```

1. **`[PENDING]` ➔ `[IN_PROGRESS]`**：
   - 提取上游节点的输出契约（强类型 DTO、接口定义）。
   - 严格遵循对应架构分类（空架子胶水层 / 清洁架构 / Feature 模块化），编写纯净生产代码。
2. **`[IN_PROGRESS]` ➔ `[SELF_VERIFYING]`**：
   - 代码编写完成，严禁口头汇报“完成”！
   - 自动生成或运行专属单元测试文件。
3. **`[SELF_VERIFYING]` ➔ `[COMPLETED]`**：
   - 必须满足两道硬门禁：`analyze` 0 Error 且自动化测试 100% 全绿。
   - 满足后自动更新节点状态为 `[COMPLETED]`，**自驱动自动触发下一个 `[PENDING]` 节点**。
4. **自愈与回滚机制**：
   - 若测试报错，自动进入自愈循环分析堆栈，局部回滚并修复。连续 3 次无法自愈才可输出客观技术阻断原因。

---

## 第三章：步骤自推演三问 (Autonomous Self-Prompting)

每一个节点开始编码前，AI 必须自驱动推演并回答三问：
1. **上游输入凭证**：上一个节点导出的接口、模型和 DTO 是什么？
2. **本节点职责边界**：本节点只做什么？绝对不碰什么？（遵循单文件 250 行与架构隔离）。
3. **完成验收基准**：写哪几个单元测试断言？预期输入输出是什么？

---

## 第四章：终局交付门禁 (Final Delivery Gate)
只有当 DAG 中所有节点均打上 `[COMPLETED]` 标签，且项目整体静态分析通过后，AI 才输出全景交付汇报，将完整结果交还用户。
