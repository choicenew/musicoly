# Legado Reader Engine Parity (Legado 阅读源解析引擎 1:1 还原技能)

## 0. 适用场景
当开发、维护或迁移网络小说、阅读源、复杂规则抓取类解析引擎（如从 Kotlin 版 Legado 1:1 翻译至 Dart）时加载本技能。

---

## 1. KT 源码审查前置 (最高技术优先级)
* **必须先看源码**：在修改任何 Dart 解析代码之前，必须先打开并阅读对应的 Kotlin 原版文件。
* **禁止猜测**：禁止凭记忆或主观猜测修改代码，没有对比 KT 源码就动手修改等同于无效操作。

---

## 2. 100% Parity (1:1 还原) 铁律
* 逻辑必须 1:1 还原原版实现；
* 禁止简化逻辑深度；
* **严禁自作聪明重构**：严禁使用“我觉得这样写更优”的逻辑去覆盖经过万人验证的原厂逻辑。

---

## 3. 标准调试 SOP
1. **先验证网站存活**：使用 `read_url_content` 抓目标 URL。若返回 DNS 失败 / JS 重定向 / 403 / 503 ➔ 分类为「网站问题」，**绝对不要去改解析代码**！
2. **再定位断点**：从测试日志定位具体失败的解析节点；
3. **再对比 KT 源码**：阅读 KT 源码逐行比对；
4. **最后精准修复**：只改逻辑偏差行，跑测试，汇报数字（成功数只能增不能减）。
